# BDDTester

Petit outil HTML/CSS/JS autonome pour vérifier rapidement des comportements liés à la couche BDD/API.

## Fichiers

- `index.html` : page de test.
- `app.js` : logique d’exécution des scénarios.
- `styles.css` : styles de l’interface de test.
- `config.template.js` : exemple de configuration locale.
