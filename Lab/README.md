# Lab

Application web Ionic/React pour expérimentations gameplay, interface et tracking.

## Structure

- `src/` : code applicatif (pages, composants, services, hooks, utilitaires).
- `public/` : ressources statiques.
- `cypress/` : tests end-to-end.

## Commandes utiles

- `npm run dev` : démarrage local.
- `npm run lint` : vérification ESLint.
- `npm run test.unit` : tests unitaires Vitest.
- `npm run test.e2e` : tests Cypress.
